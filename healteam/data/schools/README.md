# data/schools

Therapy school (流派) templates.

**W1 status:** empty. The `school-templates` task (W2) populates this with
one file per school:

- `structural.json` — 结构派 (Minuchin)
- `bowen.json` — Bowen 系统式
- `satir.json` — 萨提亚

Each file describes the school's:
- Opening style / "first 5 minutes" script.
- Intervention technique library.
- Typical session rhythm.
- Defense patterns to watch for.
- Decision rules for the doctor agent.

See PRD §6.1, §10 and the appendix for the underlying theory.
