## 1. 适合度矩阵

> **适合度**：✗ 不适合 / △ 勉强 / ✓ 适合 / ★ 强烈推荐 / ☆ 唯一最佳

| 流派 | 适合度 | 一句话原因 |
|---|---|---|
| **结构派 (Structural)** | ★ | 动力是**当下**的子系统扭曲，与结构派核心议题完全对位 |
| **Bowen 系统式** | ✓ | 代际传递明显（林建国重演其父），家谱图能立竿见影 |
| **萨提亚 (Satir)** | ✓ | 沟通姿态清晰（父亲超理智 / 母亲讨好 / 儿子打岔），冰山工作空间大 |

**结论**：3 个流派都适合本案例，**结构派作为 MVP 默认**（治疗周期短、症状聚焦、互动可见）。

## 2. 学员在三流派下需要分别练习的关键技能

### 在结构派下，学员应练习：

| 优先级 | 技能 | 验收标志 |
|---|---|---|
| P0 | 打破"父母代诉"模式（让病人先说） | 第 1 轮家庭前 30 秒内，学员自己**闭嘴** |
| P0 | **enact**（让家庭**演示**而非描述） | 第 5 轮前，学员能至少触发一次 enact |
| P0 | 边界重塑（让父亲**重新进入**夫妻子系统） | 第 10 轮前，学员能把"父亲 vs 母子"重构成"夫妻 vs 孩子" |
| P1 | 三角化提问 | 第 12 轮后，学员能主动用三角化让沉默的第三方开口 |
| P1 | 重构症状 | 第 15 轮前，学员能说出"也许不是孩子有问题，是这个家有问题" |
| P2 | 任务布置 | 收尾 5 轮，学员能给一个具体可执行的家庭任务 |

### 在 Bowen 下，学员应练习：

| 优先级 | 技能 | 验收标志 |
|---|---|---|
| P0 | 家谱图绘制 | 第 1 轮治疗前，学员画出至少**三代**家谱图 |
| P0 | 自我分化提问（区分"我感到"和"我想到"） | 第 5 轮前，学员能至少问 3 个自我分化题 |
| P0 | **去三角化**（让卷进冲突的一方**退出**） | 第 8 轮前，学员能把母亲从父子联盟中"温和抽离" |
| P1 | 代际叙事 | 第 12 轮后，学员能让父亲**讲述**自己与父亲的关系 |
| P2 | 治疗师**低情绪不站队** | 全程，学员不在父母任何一方表态 |

### 在萨提亚下，学员应练习：

| 优先级 | 技能 | 验收标志 |
|---|---|---|
| P0 | 识别沟通姿态（讨好 / 指责 / 超理智 / 打岔） | 第 3 轮前，学员能**命名**每个人的姿态 |
| P0 | 冰山模型（行为 → 感受 → 期待 → 自我） | 第 5 轮后，每次行为后学员问"冰山下面" |
| P0 | 感受镜映（"你感到的是 X 还是 Y？"） | 第 8 轮前，学员能让父亲说出情绪词 |
| P0 | 一致性沟通示范（"我感到……因为我希望……"） | 第 12 轮后，学员能让家庭成员**演练**该句式 |
| P1 | **自我观察作业**（不是行为任务） | 收尾 5 轮，学员给出"觉察"作业而非"行为"作业 |
| P2 | 治疗师**温度** | 全程，学员保持温柔、镜映、不评判 |

## 3. 预期治疗效果（每流派）

> **注意**：以下为**教学预期**，不是**临床承诺**。实际治疗效果因家庭/治疗师/外部资源差异巨大。

### 结构派（4~8 次治疗）
- **第 2~3 次**：家庭从"父母代诉"转为"病人先说"——病人第一次**直接**面对治疗师
- **第 5 次**：通过 enact，治疗师**亲眼看见**联盟/边界形态
- **第 8 次**：父亲**重新进入**夫妻子系统——夫妻第一次**直接对话**
- **收尾**：家庭带回一个**可执行**的家庭任务（结构派标志性收尾）

### Bowen（10+ 次治疗）
- **第 2~3 次**：家谱图清晰，**代际传递**被命名
- **第 5 次**：父亲**第一次**承认"我可能像我爸"
- **第 8~10 次**：母亲的**焦虑**从"儿子的问题"转为"我自己的分化"
- **收尾**：来访者**自我分化**开始（不是症状消失，而是**带症状**生活的能力提升）

### 萨提亚（8~12 次治疗）
- **第 2~3 次**：4 种沟通姿态被**全员看见**
- **第 5 次**：冰山工作让父亲**第一次**对儿子说"我感到……"
- **第 8 次**：母亲**从讨好转为一致**
- **收尾**：家庭带回**自我观察**作业（不是行为改变任务）

## 4. 学员"应该踩的坑"（教师预设的失败模式）

> 这些是 HealTeam 学员**在陪练中最容易犯的错**，治疗师在演示中**故意**会让学员踩坑，然后让旁观者 Agent 提示"这是 XX 流派的红旗"。

### 结构派学员的常见错
1. ❌ **替家庭说话**——把"孩子不想上学是因为……"直接说出来
2. ❌ **给建议**——"你们应该每天一起吃饭"
3. ❌ **卷入三角**——站父亲一边或站母亲一边
4. ❌ **过早给任务**——还没看清结构就布置"行为任务"

### Bowen 学员的常见错
1. ❌ **理论轰炸**——大段讲代际传递理论
2. ❌ **问感受**——Bowen 流派不靠感受，靠**自我分化**思考
3. ❌ **给结论**——直接说"你在重复你爸的模式"
4. ❌ **卷进三角**——给父亲或母亲任何一方的"建议"或"立场"

### 萨提亚学员的常见错
1. ❌ **变冷**——变成"中性客观"的治疗师
2. ❌ **问行为**——"你今天怎么没去上学"（这是症状定位）
3. ❌ **给行为任务**——"下周开始每天早起跑步"（这是行为主义）
4. ❌ **跳到自我层**——还没建好安全感就追问"你对自己的期待"

## 5. 教学顺序建议（教师用）

> HealTeam W2 起的训练推荐顺序（**仅推荐**，可按学员情况调整）：

```
Week 1:  结构派 (Structural)     ← 短、控、可见，最快建立"我能做家庭治疗"信心
Week 2:  Bowen 系统式            ← 长程、思考性，扩展"我能处理代际"的能力
Week 3:  萨提亚 (Satir)          ← 温度、镜映，扩展"我能处理情绪"的能力
Week 4:  综合（同一案例跑 3 流派）  ← 横向比较，建立"我会选流派"的能力
```

MVP 阶段（v0.2）只支持结构派。Bowen / 萨提亚 v0.3 起开放。
