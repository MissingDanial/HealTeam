# S5 交付与验收记录

交付日期：2026-11-10（Asia/Shanghai）  
产品版本：0.6.0；业务协议：0.5.0；数据库：schema v2。  
目标：让单人本地训练可以直接启动，并能完整备份、搬移和恢复记录。

## 已交付

- Windows 一键准备、启动、停止、环境检查，以及备份、验证、恢复入口。
- 包含生产网页的本地运行包；首次准备只安装 Python 依赖，不需要重新安装前端依赖或构建网页。
- 前台启动器同时管理 API 和网页；重复启动、端口冲突、正常停止、Ctrl+C 及监督进程强制退出都有明确处理。
- 版本、平台、Node 主版本和完整文件 SHA-256 校验；网页访问不再写入受校验的构建目录。
- 完整 SQLite 备份，保留会话、持久事件、幂等收据、报告和人工复核；归档只包含清单与数据库。
- 恢复默认不覆盖；显式覆盖时先保存并验证旧库安全备份，再在阻止并发写入的条件下替换。无法安全覆盖时保留旧库，要求恢复到新文件。
- 支持解压到含空格和中文的目录，从其他工作目录启动；维护工具也以自身副本为准，不误用继承的旧项目根目录。

私有 DeepSeek 配置仅保留在当前工作区 `.env`，不进入交付包。S5 验收全部使用 mock、本地 fixture 和临时数据库，外部付费模型请求为 0，未向外发送训练或复核内容。桌面原项目未修改。

## 验收范围

全套回归与启动器修复后复测按测试标识合并，**588 passed、3 skipped、0 项待解决失败**；1 条既有 LangGraph 弃用预告。运维与交付测试 106 项通过。检查明细见 [s5-verification.json](s5-verification.json)。运行环境为 Windows x64、Python 3.12.13、Node.js 24；Python 3.11、Node.js 22 是源码目标兼容范围，本轮未在这些版本实际运行。当前预构建包只接受 Node.js 24。

备份测试覆盖运行锁、WAL 快照、完整性与业务引用、未知版本、归档异常、大小限制、安全副本、无覆盖竞争、覆盖期间外部写入，以及搬移后的维护路径。启动器测试覆盖真实生产网页、重复启动、鉴权停止、进程异常退出与控制请求不跟随重定向。

全套回归曾发现端口被占用时启动器加载模型模块过慢，导致冲突提示超过测试的 20 秒等待。已把端口预检提前到模型模块加载之前；修复后复测整个启动器模块。合并统计保留每个测试的最终结果，机器记录同时保留全套运行与修复复测的分项数量。

复测还定位了 Windows 原子发布状态文件时路径前缀偶发变化的竞态。现改为固定父目录、拒绝重解析点、单次打开并限长读取；文件恰好在停机时删除则视为已停止。新增三项状态读取回归及两项测试进程清理回归，避免测试异常留下实例后使后续场景跳过；最新启动器还在已搬移副本复验报告浏览器流程。

生产运行包完成 8 项原有浏览器训练流程，页面错误为 0。另完成保存训练与人工复核、停止后备份、解压到中文和空格目录、恢复到相对数据库路径、核对病例来自新副本、原报告和修订一致、重复请求不新增记录、浏览器打开恢复报告及再次重启。浏览器使用本机 Edge，无外部模型请求。

源码资源清单与解压后离线运行、预构建清单与归档完整性、私有配置排除、wheel 构建与干净运行环境导入均纳入交付检查。测试服务结束后停止，不占用日常使用端口。

开发证据保存在工作区 `.cache/s5-pytest.xml`、`.cache/s5-pytest.log`、`.cache/s5-acceptance-final/` 和 `.cache/s5-wheel-build.log`，不进入公开包。可复验的维护与交付测试在 `tests/operations/`；训练浏览器流程使用 `scripts/browser_training_smoke.py`。

## 使用与交付文件

日常使用建议选择 `HealTeam-local-0.6.0-win32-x64.zip`，需要修改开发时选择 `HealTeam-S5-2026-11-10.zip`。每包附 SHA-256 文件；二者均不含系统 Python/Node、私有 `.env`、训练数据库、备份和本机运行状态。

首次解压后进入 `HealTeam-main/healteam`，先双击 `安装与构建.cmd`，再双击 `开始使用.cmd`。系统需预先安装 Python 3.11/3.12 和 Node.js 24，首次依赖安装需要联网；新副本默认 mock。工作区现有副本保留原有私有配置。

网页默认入口 `http://127.0.0.1:3000`，本次预构建包的内部 API 为 18000；手工开发默认 8000。端口变更、明确重建、备份恢复与回退步骤见 [S5 运行手册](s5-runbook.md)。完整备份包含对话、姓名与备注，应私下保管；它与校准页的去标识化导出用途不同。
