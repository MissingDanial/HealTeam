## 使用

启动方式见[项目 README](../README.md)。新会话完成后，在复盘中查看试行量规并展开本机人工复核；保存后从 `/calibration` 查看有效配对和下载数据。旧 S3 会话不追补新评价，需新练习生成新版量规。

升级前停止后端并备份原数据库；首次启动会从 schema v1 事务升级到 v2。回退旧版本时使用升级前备份。具体请求、统计分母及数据边界见 [S4 约定](s4-contracts.md)。

交付文件为工作区 `output/HealTeam-S4-2026-11-04.zip` 及 SHA-256；包内无私有 `.env`、数据库、复核记录、缓存或依赖目录。新解压默认 mock，工作区现有副本保留用户的 DeepSeek 私有配置。

开发证据位于 `.cache/s4-pytest.xml`、`.cache/s4-pytest.log` 和 `.cache/browser-s4/`，不包含在源码包；可复验脚本为 `scripts/browser_evaluation_smoke.py`。量规资源与合成参考样例包含在源码中。
