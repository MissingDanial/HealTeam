# 三流派治疗路径对比说明

> 路径：`healteam/docs/schools-comparison.md`
> 适用版本：HealTeam W1 MVP
> 主要文献已在各流派模板中列出，本文档做横向对比

---

## 0. 一句话区分

> **结构派**："你们家**怎么**做"——关注当下互动模式，重塑子系统边界。
> **Bowen**："你们家**几代人**都怎么传"——关注代际链条，提升自我分化。
> **萨提亚**："你们**感到**什么"——关注沟通姿态+冰山下的期待与自我。

---

## 1. 维度对比表

| 维度 | 结构派 (Structural) | Bowen 系统式 | 萨提亚 (Satir) |
|---|---|---|---|
| **流派之父** | Salvador Minuchin | Murray Bowen | Virginia Satir |
| **流派 ID** | `School.STRUCTURAL` | `School.BOWEN` | `School.SATIR` |
| **核心隐喻** | 房子 / 边界 / 子系统 | 代际链条 / 三角关系 | 冰山 / 姿态 / 镜映 |
| **关注的"问题"** | 家庭**当下**的互动模式 | 跨代际的情感传递 | 个体的**自我价值**与沟通姿态 |
| **症状定位** | 症状是**家庭失衡**的副产品 | 症状是**分化不足**的代偿 | 症状是**求生存姿态**的副产品 |
| **治疗师姿态** | 主动、控场、导演 | 低情绪、思考者、不站队 | 温暖、镜映、接纳 |
| **开场的第一问** | "你们家**怎么运作**？" | "你家**几代人**都怎么 XX？" | "你最想**被听到**的一句话？" |
| **典型干预** | 加入 / 追踪 / enact / 边界重塑 / 三角化提问 / 重构症状 | 家谱图 / 自我分化提问 / 去三角化 | 冰山 / 沟通姿态识别 / 感受镜映 / 转化 |
| **拒绝使用的工具** | 家谱图、感受反映 | enact、感受反映 | 三角化、家谱图 |
| **红旗信号** | 治疗师给建议 / 治疗师变家庭新权威 | 治疗师站队 / 治疗师卷进三角 | 治疗师变冷 / 治疗师问行为 |
| **理论原著** | Minuchin 1974; Minuchin & Fishman 1981; Minuchin et al. 1978 | Bowen 1978; Kerr & Bowen 1988; Titelman 2014 | Satir 1972; Satir et al. 1991; Satir 1988 |

## 2. 同一个家庭动力，三个流派会"看到"什么

以 MVP 案例 `teen-truancy-01`（高一男生拒学）为例：

### 案例动力摘要

> 父亲用理性化与工作逃避维持情感距离；母亲与儿子形成跨代际情感联盟；儿子通过躯体化与退行表达对"被卡在父母中间"的隐性抗议。表面"父母联盟对抗孩子"，实际"父母联盟早已破裂，孩子被母亲拉为情感代偿"。

### 三个流派的"读法"

#### 结构派会看到
- **边界类型**：父亲—母亲—儿子之间的三角化（父亲被孤立到夫妻子系统之外）
- **结构病灶**：父-母-子的"刚性联盟 vs 孤立"配置，而非"父母联盟对抗孩子"
- **干预入口**：用 enact 让家庭**演示**他们**不在讨论**的冲突；用边界重塑让父亲**重新进入**夫妻子系统

#### Bowen 会看到
- **代际链条**：林建国自己父亲对他的严格管教 → 林建国对儿子的高期望（重复父亲的模式）
- **自我分化水平**：父亲（高功能低分化）、母亲（中分化高焦虑）、儿子（低分化、躯体化退行）
- **干预入口**：画家谱图让父亲**看见**自己正在重复父亲的模式；用自我分化提问让父亲**区分**情绪和思考

#### 萨提亚会看到
- **沟通姿态**：父亲=超理智（rationalizing）/ 母亲=讨好（pleasing）/ 儿子=打岔（irrelevant）+ 退行
- **冰山层**：每个姿态下面藏着对**被爱 / 被认可**的深层期待
- **干预入口**：用感受镜映让父亲**听见**儿子的"我撑不住了"；用一致性沟通让母亲**示范**"我感到……因为我希望……"

## 3. 关键决策点：什么时候用哪个流派

### 优先选**结构派**，当：
- 家庭互动**当下**就能看到清晰的子系统扭曲（联盟 / 三角化 / 边界模糊）
- 病人主诉聚焦在"症状"或"行为问题"
- 学员擅长**导演**和**控场**
- 案例档期短（4~8 次治疗可期）

### 优先选**Bowen**，当：
- 家庭中存在**明显**的代际传递（来访者的父母有类似问题）
- 家庭愿意做**长期**咨询（10+ 次起）
- 学员擅长**思考性提问**和**长程节奏控制**
- 关键人物愿意做"自我分化"的功课

### 优先选**萨提亚**，当：
- 家庭**情绪张力**高，但难以命名
- 来访者**自我价值**明显受损（"我不够好"反复出现）
- 学员擅长**温度**和**镜映**
- 案例涉及**早期创伤**或**依恋议题**

### MVP 默认选择：**结构派**

> 青少年拒学这种案例，时间压力大（家长通常 4~8 次就不耐烦了），症状聚焦，互动模式肉眼可见——结构派的"快、准、控"最匹配。MVP 默认 `School.STRUCTURAL`。
>
> 但 HealTeam 的设计**允许学员切换流派**（在创建 Session 时选择 `school` 参数），所以这三种治疗路径都是可演练的。

## 4. 三个流派的"风险点"

| 流派 | 风险 | 治疗师反制 |
|---|---|---|
| 结构派 | 治疗师**过强**，变成家庭新权威 | 经常**自我让位**，把发言权交还给家庭 |
| Bowen | 治疗师**理论太多**，来访者听不懂 | 大量**比喻 + 具象化**（家谱图、棋子、地图） |
| 萨提亚 | 治疗师**温度过高**，边界松 | 守住"治疗师**不是**新父母"的位置 |

---

## 5. 旁观者 Agent 在三流派下的"听法"区别

旁观者（observer Agent）作为后台督导员，**根据当前流派**采用不同的"听法"：

| 流派 | 旁观者最该**警惕**的信号 | 旁观者最该**提醒**治疗师的机会 |
|---|---|---|
| 结构派 | 治疗师给出建议；治疗师在替家庭说话 | 家庭**在描述**而非**演示**时，立刻建议 enact |
| Bowen | 治疗师站队 / 卷进三角 | 出现**代际传递**叙事时，建议画家谱图 |
| 萨提亚 | 治疗师变冷 / 治疗师问行为而非感受 | 家庭**在行为**（不是感受）时，建议"冰山下面" |

旁观者 Agent 的详细 hint 规则已在各 `data/schools/*.md` 的 §7 节定义。
