## DeepSeek 真实连接

先读取官方模型列表，返回 deepseek-flash 和 deepseek-v4-pro；采用 deepseek-flash。仅发送一次最多 16 个输出 token 的短测试，未发送病例或训练对话。HTTP 200、正常 stop、有效最终内容；供应商报告输入 8、输出 1、共 9 token。

自动化完整训练、故障和浏览器测试全部使用本地模拟模型服务，外部付费调用为 0。上述一次真实短测试单独计数，不能据此声称已完成 DeepSeek 多轮仿真质量验收。

## 本次验证重点

三个 provider × 三个流派的 API 完整闭环通过。鉴权失败、限流、服务错误、坏 JSON、错误角色和截断均保存安全失败状态，不伪造模板回应。复盘虚假引用被拒绝，改正后重试只生成报告，不重复原对话。

预算测试覆盖未结算调用跨库重开、重复结算、调用/总量上限，以及输入或输出单边未知时的独立预留。审查发现“已知较大输入吃掉未知输出预算”的缺口，已修复并增加回归。角色输出审查还补上正确 actor 内夹带其他角色脚本的拒绝逻辑。

所有新测试使用临时 SQLite 文件和本地假 key。公共 API、SSE 和截图不含认证信息、端点明文、私有提示词资源或内部账本事件。
